# NerdPOS — بروتوتايب فرونت إند للتجربة (Expert Prototype)

نسخة تجريبية كاملة **من غير باك إند**: كل الطلبات بتتمسك جوه المتصفح وبتعدي على "سيرفر وهمي" مبني من العقود الحقيقية
(`operations.json` و `errors.json` و `openapi`) وقواعد `02_MOCK_RULES`. نفس أكواد الأخطاء، ونفس الصلاحيات، ونفس قواعد
الموافقات والـ idempotency — والرسايل بالعربي المصري (والإنجليزي من ملف واحد).

> **مش منتج حقيقي.** البيانات كلها وهمية ومتخزنة في المتصفح (localStorage). مفيش أي اتصال بسيرفر أو منصة ضرائب حقيقية.

## التشغيل

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # نسخة static في dist/ (base './' — تتفتح من أي مكان)
npm run artifact   # نفس النسخة + dist/artifact.html للنشر كـ Artifact على claude.ai
```

المتطلبات: Node 18+. أول ما `npm run dev` يشتغل بيولّد `src/contracts/*.json` من `docs/pack/` (سكربت `scripts/build-contracts.mjs`).

## الأجهزة (Terminals)

الشريط اللي فوق فيه زرار لكل جهاز. كل جهاز ليه دخوله وجلسته وشاشته — بالظبط كأنه تابلت منفصل.
زرار **تقسيم الشاشة** بيعرض جهازين جنب بعض (مثلاً تابلت الويتر وشاشة المطبخ) وأي تغيير بيظهر على الاتنين فوراً.

| الكود | الجهاز | ملاحظات |
|---|---|---|
| T1 | كاشير (درج) `DEMO-CASH-1` | جلسة درج، دفع كاش/كارت، X/Z، جهاز ضريبي |
| T2 | تابلت الويتر `DEMO-FLOOR-1` | الصالة والشيكات، من غير درج |
| K1 | شاشة المطبخ `DEMO-KDS-1` | التذاكر حسب المحطة |
| ADM | مكتب المدير `DEMO-ADMIN-1` | الإعدادات والتقارير والموافقات |
| B2 | تابلت الفرع التاني | منيو الفرع التاني (من غير أسعار → `PRICE_NOT_FOUND`) |
| BO | باك أوفيس من غير جهاز | عمليات الإدارة اللي مش محتاجة X-Terminal-Id |

## أدوات العرض (الشريط اللي فوق)

- **الساعة الوهمية** — تقديم الوقت أو ضبطه على توقيت القاهرة (يوم العمل بيتقفل الساعة 04:00). بيشغّل التنبيهات (12/20 ساعة)، وإعادة محاولة الطباعة، وإرسال الإيصالات الإلكترونية.
- **المحاكاة** — طابعات (واقعة/ورق خلص)، شاشة المطبخ واقعة، منصة الإيصال الإلكتروني (ETA) واقعة/بترفض، الشبكة (تأخير، الرد يضيع، أوفلاين).
- **لوحة الإعدادات (Policy Panel)** — كل سياسة بقيمتها الحالية وقيمة بروفايل مصر والنطاقات، وتتغير فوراً. *التغيير بيطبق على العمليات الجديدة بس* (الشيك المفتوح محتفظ بنسخة الإعدادات اللي اتفتح بيها).
- **الرحلات (Walkthrough)** — بيعيد J-R1..R4 و J-A1 (والكاونتر والأعطال) خطوة بخطوة: مين، على أنهي جهاز، المتوقع، والعمليات من العقد. "روح للجهاز" بيفتح الشاشة الصح، و"نفّذ تلقائي" بيعمل الخطوة بنفس الـ API.
- **سيناريوهات الفشل** — N1–N12 (كل واحد بيتشغل ويقول نجح/فشل) + متصفح الـ 1000 موقف مع "سجّل كملاحظة".
- **وضع الملاحظات** — دوس على أي حاجة في أي شاشة واكتب ملاحظة؛ "الملاحظات" بتصدّر `feedback.json` ومعاه `policy_snapshot` والجهاز والشاشة والمستخدم.
- **سجل الطلبات (API)** — كل طلب: العملية، المسار، الحالة، كود الخطأ، `X-Command-Id`، و`Idempotent-Replayed`.
- **اللغة / الثيم** — عربي ↔ English، داكن/فاتح/فاخر.
- **إعادة الضبط** — بيانات العرض، أو تركيب فاضي من الصفر، أو تصدير/استيراد قاعدة البيانات.

## شارة حالة الباك إند

كل شاشة وكل قسم عليه شارة:

- **مبني** — العمليات موجودة في `operations.json` كـ BUILT.
- **متصمم** — موجودة في العقد بس لسه مش مبنية (PD_HELD / DESIGNED).
- **مقترح** — مش موجودة في العقد؛ البروتوتايب اقترحها عشان الشاشة تكمل (القائمة في `PROTOTYPE_GAPS.md`).

## اقتراح لترتيب التجربة

1. **الرحلات ← يوم صالة كامل (J-R1)** ← "ابدأ من الأول" وبعدين امشي خطوة خطوة بـ "روح للجهاز" واعمل الخطوة بإيدك (أو "نفّذ تلقائي").
2. افتح تقسيم الشاشة T2 + K1 وابعت جولة — شوف التذكرة بتظهر على المطبخ.
3. غيّر سياسة من لوحة الإعدادات (مثلاً موافقة إلغاء الصنف بعد الإرسال) وجرّب تاني.
4. المحاكاة ← وقّع الطابعة، ادفع شيك، وشوف طابور الطباعة وإعادة المحاولة؛ أو ضيّع رد الدفع وشوف شاشة "النتيجة مش معروفة".
5. **تركيب من الصفر (J-A1)** — من سيرفر فاضي لحد أول بيع وأول تقرير Z.
6. شغّل N1–N12 من "سيناريوهات الفشل".

## الفلوس

العرض بالجنيه المصري بخانتين عشريتين؛ الحساب جوه بـ `decimal.js` على 4 خانات، **ومفيش float** في أي حساب فلوس.
التسعير كله على "السيرفر الوهمي" (الأسعار محفوظة في السطر، الخدمة بتتحسب من أول سطر، توزيع الخصم بأكبر باقي، الضريبة حسب مجموعة الضريبة).

## هيكل المشروع

```
docs/pack/                 حزمة البروتوتايب الأصلية (المراجع)
scripts/build-contracts.mjs يولّد src/contracts/*.json من الحزمة
scripts/journeys-test.ts    تشغيل كل الرحلات و N1–N12 من غير متصفح
src/mock/                   السيرفر الوهمي: kernel (المسارات/الصلاحيات/idempotency/الموافقات/الأوديت)،
                            handlers/*، pricing، outbox (المطبخ/الطباعة/الإيصال الإلكتروني)، clock، seed، store
src/api/client.ts           عميل fetch عادي — نفس الكود اللي هيكلم الباك إند الحقيقي
src/app/                    الأجهزة، الهوكس (useQuery/useCommand/الموافقات/النتيجة المجهولة)، تسجيل الشاشات
src/screens/                شاشات التشغيل والإدارة
src/demo/                   أدوات العرض (اللوحات، الرحلات، السيناريوهات، الملاحظات)
src/i18n/                   t('النص العربي') + en.ts (ملف الإنجليزي الوحيد) + رسايل الأخطاء
src/theme/tokens.css        ملف الثيم الوحيد (ألوان الديزاين سيستم القديم)
```

### تغيير الثيم

كل الألوان متغيرات CSS في `src/theme/tokens.css` (`[data-theme="dark" | "light" | "luxury"]`). استبدال الملف ده كفاية.

### إضافة ترجمة

النص العربي هو المفتاح: `t('افتح الشيك')`. الإنجليزي في `src/i18n/en.ts`.
`node scripts/extract-i18n.mjs` بيطلع النصوص اللي لسه ملهاش إنجليزي.

### اختبار سريع من غير متصفح

```bash
npx esbuild scripts/journeys-test.ts --bundle --platform=node --format=esm --outfile=/tmp/jt.mjs && node /tmp/jt.mjs
```

بيشغّل J-R1..R4 و J-A1 والكاونتر والأعطال و N1–N12 ويطبع `FAILURES: 0` لو كله تمام.
